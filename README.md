# GPR — TurtleGPR

Ground-penetrating radar (GPR) designed to detect turtle nests buried in the sand, developed as a student project at INSSET (Université de Picardie Jules Verne, Saint-Quentin) for WWF.

> 🚧 **Work in progress** — the project is at an early stage and its structure will evolve.

## About the project

Sea turtles bury their eggs in the sand, which makes nests hard to locate and protect. The goal of this project is to build a ground-penetrating radar able to detect these nests without digging, so that conservation teams can find and monitor them more easily.
